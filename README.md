# TeraBox Video Links Directory

An independent static website that lists TeraBox shared-link bundles and publishes practical help for opening links, troubleshooting access issues, and staying safe.

**Live site:** <https://teraboxlinks.pages.dev/>

## What the site does

- Lists 20 external TeraBox bundle links on the homepage.
- Explains how to open a shared link in a browser or the official TeraBox app.
- Provides troubleshooting, safety, FAQ, legal, and contact pages.
- Does not host, upload, or stream the files linked from the directory.

Shared-link availability, file contents, access requirements, and share codes are controlled by TeraBox and the person who shared each link. The site is independent and is not affiliated with TeraBox.

## Search and crawler files

- `robots.txt` publishes crawler directives and the sitemap location.
- `sitemap.xml` lists the site's indexable HTML pages.
- `llms.txt` summarizes the site's scope and links to its main guides for AI retrieval systems.

These files make site information easier to discover; they do not guarantee crawling, indexing, ranking, or inclusion in AI-generated answers.
