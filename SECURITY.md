# Security Policy

## Supported Version

The current version deployed from the `main` branch is the supported version
of this static website.

## Reporting a Security Problem

Security problems may include:

- a malicious or deceptive external link;
- an unexpected redirect;
- exposed private information;
- a compromised repository or deployment;
- unsafe third-party content;
- a vulnerability in the website code or workflow.

### Reporting contact

Email security concerns to [www.terabox.us@gmail.com](mailto:www.terabox.us@gmail.com)
with a brief, non-sensitive description and the affected public page URL.
Do not send passwords, access tokens, identity documents, private addresses,
confidential evidence, or personal information belonging to another person.
If more detail is needed, request a secure communication method before
sharing sensitive material. GitHub Issues are currently unavailable for this
repository.

## Malicious or Illegal External Material

This website does not directly host files available at third-party
destinations.

If an external destination contains malicious, illegal, infringing,
non-consensual, exploitative or underage material:

1. Do not download, copy or redistribute it.
2. Email the site operator at the address above with the affected page URL and
   a short description.
3. Report the material to the external hosting provider.
4. Contact the appropriate authorities where required.

Removing a directory link from this website does not remove the underlying
file from a third-party service.

## Response Process

After receiving a sufficiently detailed report, the site operator may:

1. review the affected page and destination;
2. temporarily disable the relevant link;
3. request additional non-sensitive information;
4. remove or correct the link;
5. notify the relevant platform where appropriate.

No fixed response time is guaranteed, but reports involving immediate safety
risks should be prioritized.

## Scope

This policy applies to:

- `[https://teraboxlinks.pages.dev/](https://teraboxlinks.pages.dev/)`;
- source files in this repository;
- the GitHub Pages deployment workflow;
- external links published by the website.

Third-party services, including TeraBox, Google Play and GitHub, operate under
their own security policies.
